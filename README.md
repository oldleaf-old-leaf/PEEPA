Simple bilingual landing page for **WeChat users** who want a short, copy-friendly briefing on the Solana token **$PEEPA**.

WeChat’s in-app browser often fails to open X, Binance, DexScreener, or even GitHub. This page is meant to be:

- opened from a GitHub / GitHub Pages link  
- screenshotted and dropped into a WeChat group  
- used to **copy the contract address** in one tap  

It is **not** an official issuer site, not a wallet, and **not financial advice**.
